# Fonts

Made by `npm run fonts` (scripts/fonts.mjs) from Google Fonts, keeping only the characters the site uses.

- Bodoni Moda (bodoni.woff2, bodoni-italic.woff2): https://fonts.google.com/specimen/Bodoni+Moda
- Literata (literata.woff2): https://fonts.google.com/specimen/Literata
- Pinyon Script (pinyon.woff2): https://fonts.google.com/specimen/Pinyon+Script

All three are under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows using, subsetting
and serving them on a website. Copyright: Bodoni Moda © The Bodoni Moda Project Authors; Literata © The Literata
